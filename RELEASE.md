# Canadian release

Use a reviewed commit from this repository and record the full SHA with each
projection. Install it in a fresh environment from a checkout at that SHA.

Run the core test suite and strict Ontario examples, then install a built wheel
in a fresh environment and rerun the examples. GitHub hosts this fork's source.
The distribution and Python import names match Life Model for compatibility.

See the [Ontario examples](examples/canada/README.md) for the supported inputs
and synthetic cases.
